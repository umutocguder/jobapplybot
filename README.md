## 🎯 Özellikler
- **ATS Anahtar Kelime Uyumluluk Skoru**: İlan metni ile CV içeriğini semantik olarak kıyaslar ve yüzde puan üretir.
- **Başvuru Takip Defteri**: Şirket, pozisyon, tarih, mülakat aşamaları ve teklif durumunu yerel diskte takip eder.
- **Sıfır Bağımlılık**: Harici paket kurulumuna ihtiyaç duymadan doğrudan Python 3 standart kütüphanesiyle çalışır.
- **Çift Kademeli Telemetri**: Yerel JSONL loglama ve Firebase Cloud entegrasyonu.
